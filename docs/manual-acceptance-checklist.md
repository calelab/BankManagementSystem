# 最终人工点击验收清单

建议使用专门的演示账户，不使用真实密码或真实业务数据。开始前确认当前程序启动日志显示 `AES-256-GCM 加密模式`。

## 一、营业员与开户

- [ ] 启动程序，首屏显示营业员工号入口，窗口布局和文字无截断；
- [ ] 输入无效工号，确认停留在入口并显示明确错误；
- [ ] 输入 `E03`，进入工作台；
- [ ] 打开“开户”，填写演示姓名、地址和两次相同密码；
- [ ] 先验证空字段或两次密码不一致会被拒绝，再完成开户并记录新账号；
- [ ] 返回工作台，确认新账号已自动带入储户登录页。

## 二、登录与失败限制

- [ ] 使用一次错误密码登录，确认出现统一的“账号或密码错误”提示；
- [ ] 使用正确密码登录，确认进入账户中心；
- [ ] 另行准备测试账号，连续输入错误密码五次，确认账户临时锁定；
- [ ] 在 60 秒锁定期内输入正确密码仍被拒绝，锁定期结束后可正常登录。

## 三、多笔定期存款与动态表格

- [ ] 对当前没有存款的新账户新增第一笔一年期存款；
- [ ] 确认表格从 0 行变为 1 行后列宽立即正常，无需点击表头；
- [ ] 新增第二笔三年期存款和第三笔五年期存款；
- [ ] 确认三笔存款拥有不同存款编号，原始本金、剩余本金、储种、利率及到期日正确；
- [ ] 确认五年期摘要显示 3.50%，到期日为存入日后五个日历年；
- [ ] 缩放窗口并拖动表头，确认表格仍可阅读且允许手动调整列宽；
- [ ] 确认下方交易表有对应三条存款流水。

## 四、支取

- [ ] 选中一笔未到期存款，输入部分本金，确认预览显示“提前支取”、利息和实际支付额；
- [ ] 点击取消，确认本金和流水均未变化；
- [ ] 再次预览并确认，确认只减少所选存款的剩余本金，并新增一条提前支取流水；
- [ ] 使用一笔到期日不晚于业务日期且仍有本金的专用测试存款，确认显示“到期支取”；
- [ ] 确认到期后额外等待天数不会增加利息；
- [ ] 全额支取后确认该笔存款默认隐藏；勾选“显示已结清存款”后可见，但支取按钮保持禁用。

到期支取需要预先准备固定业务日期的测试数据，不要直接修改真实加密文件制造到期状态。

## 五、资料、密码、挂失与解挂

- [ ] 修改姓名和地址，确认账户中心立即刷新；
- [ ] 修改密码时先验证错误当前密码或两次新密码不一致会被拒绝；
- [ ] 成功改密后退出账户，确认旧密码失效、新密码可登录；
- [ ] 点击挂失，在确认框检查按钮文字为“取消/确认”，完成挂失；
- [ ] 确认存款、支取、修改资料和修改密码按钮禁用，查看和退出仍可用；
- [ ] 使用错误密码解除挂失，确认失败且账户仍挂失；
- [ ] 使用正确密码解除挂失，确认按钮状态恢复。

## 六、查询、备款与审计

- [ ] 打开“全部储户与查询”，确认账号、姓名、地址、状态、挂失日期、营业员、存款笔数和剩余本金列可读；
- [ ] 分别验证账号精确查询、姓名模糊查询、正常/挂失状态筛选和重置；
- [ ] 确认营业员查询页不显示密码、Salt、哈希或完整交易明细；
- [ ] 打开账户中心，确认当前储户的全部定期存款和全部交易流水可见；
- [ ] 打开未来三日备款，确认固定显示明天、后天、大后天三行；
- [ ] 使用到期日落在这三天内的专用数据核对本金、到期利息和预计备款；
- [ ] 确认今天到期和第 4 天到期的存款不计入，空白日期仍显示零；
- [ ] 打开当前营业员审计日志，确认动作、结果和失败原因显示简短中文；
- [ ] 过滤“储户登录”等操作类型，确认筛选结果正确；
- [ ] 找到错误密码记录，确认结果为“失败”、原因为“密码错误”；
- [ ] 确认审计列首次进入即正常显示，失败原因列不会独占表格。

未来三日非零备款需要预先准备相应到期日数据，推荐使用测试夹具或专门演示数据目录。

## 七、重启恢复与加密文件

- [ ] 记下账户资料、三笔存款、部分支取结果和审计条数，正常退出程序；
- [ ] 重新启动并再次登录，确认资料、剩余本金、流水、挂失状态和审计均恢复；
- [ ] 在平台应用数据目录确认存在 `bank_data.enc`、`config/master.key` 和相应 `audit/*.audit.enc`；
- [ ] 确认不存在由本次加密运行生成并覆盖的 `bank_data.json` 或 `*.audit.json`；
- [ ] 仅查看文件名和权限，不打开、复制到报告或展示 `master.key` 内容；
- [ ] 最后检查各页面首屏、动态刷新、按钮状态、中文提示及窗口缩放均正常。

验收数据如需迁移或备份，必须整体复制应用数据目录，使 `master.key`、核心密文和加密审计始终保持配套。
